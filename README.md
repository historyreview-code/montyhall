# Monty Hall · 三门问题 & 靓妹硬币

概率谜题互动游戏集合，沉浸式 HTML 单页应用。

---

## 🚪 三门问题 (Monty Hall Problem)

**`index.html`** — 经典的蒙提霍尔问题交互版

三扇门后有一辆汽车和两只山羊。选一扇后，主持人打开一扇空门，你选择坚持还是换门？

- 3D 翻转门动画，音效 + 语音引导
- 实时统计：坚持 vs 换门胜率
- 自动模拟（批量模拟 + 进度反馈）
- 每 20 局小结弹窗
- 键盘无障碍、响应式布局

**结论：换门胜率趋近 66.7%，坚持只有 33.3%**

---

## 🪙 靓妹硬币 (Two-Coin Problem)

**`coin-game.html`** — 两枚硬币概率问题交互版

两枚硬币：一枚 **金+银**，一枚 **金+金**。随机摸一枚翻一面。看到金色后，坚持还是换？

- 3D 翻转硬币动画，音效 + 语音引导
- 实时统计：坚持 vs 换币胜率
- 每 20 局小结弹窗
- 键盘无障碍、响应式布局

**结论：坚持胜率趋近 66.7%，换币只有 33.3% — 与三门问题正好相反！**

---

## 🤔 为什么结论相反？

| 问题 | 坚持胜率 | 换的胜率 | 原因 |
|------|---------|---------|------|
| 🚪 三门问题 | 33.3% | **66.7%** | 主持人排除一扇空门后，换门相当于选了两次 |
| 🪙 靓妹硬币 | **66.7%** | 33.3% | 金+金有 2 个金面，金+银只有 1 个，看到金色后手上更可能是金+金 |

两个问题都展示了同一个核心概念：**额外信息改变概率分布**，但方向截然不同。
